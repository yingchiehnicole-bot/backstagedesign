# 訂單管理後台 — Flexible Column Layout（FCL）

以 SAP Fiori 的 Flexible Column Layout 為藍本，實作一套三欄式後台資料管理介面。純 HTML / CSS / JavaScript，不需要建置工具，直接用瀏覽器開啟 `index.html` 即可。

```
index.html        頁面骨架（Shell + 三個欄位 + 兩條分隔線）
css/fcl.css       設計 token、欄位版面、container query、響應式與深色主題
js/data.js        模擬訂單資料（固定種子，每次載入一致）
js/app.js         FCL 控制器：路由、版面計算、各欄渲染、表單、拖曳
```

## 1. 三欄架構與導航流轉

| 欄位 | 內容 | 互動 |
| --- | --- | --- |
| **第一欄 Master** | 訂單清單（List Report）＋搜尋、狀態篩選 chips、排序 | 點選一列 → 開啟第二欄；↑↓ 鍵可在清單間移動 |
| **第二欄 Detail** | 訂單 Object Page：標頭（客戶、狀態、KPI）、區段錨點、商品明細、一般資訊、出貨資訊、活動紀錄 | 點選「商品明細」任一列 → 開啟第三欄；可直接變更訂單狀態 |
| **第三欄 Detail-Detail** | 商品明細編輯表單：數量、單價、折扣、出貨倉、預計出貨日、備註，即時計算小計 | 儲存／還原、上一項／下一項；已出貨或已取消的訂單改為唯讀 |

- 導航狀態寫在 URL hash：`#/SO-10240/1?fs=end`，可直接分享連結、重新整理保留畫面、支援瀏覽器上一頁。
- 第三欄有未儲存的變更時，關閉欄位、切換項目或按上一頁都會先跳出確認。
- `Esc`：先退出全螢幕，再依序關閉第三欄、第二欄。

## 2. 版面模式與比例

Shell 右上角的分段按鈕切換比例預設值（目前生效的模式會以全亮顯示）：

| 模式 | 預設比例 |
| --- | --- |
| 雙欄 | `33 : 67`（強調詳情）／`25 : 75` |
| 三欄 | `25 : 50 : 25`／`33 : 33 : 33` |

- **全螢幕聚焦**：每一欄標題列右上角都有 ⤢／⤡ 按鈕，將該欄放大到 100%，再按一次或按 `Esc` 回到多欄。全螢幕狀態寫進 URL（`?fs=mid`）。
- **拖曳微調**：欄與欄之間的分隔線可以拖曳（每欄最小 220px），也可用鍵盤 ←／→ 調整；雙擊分隔線還原為預設比例。自訂寬度依「裝置 × 可見欄位 × 比例」分別記憶。
- 欄寬以 `flex-grow` 表示比例並加上轉場，開合欄位時會平滑滑動。

## 3. 跨裝置響應式

| 斷點 | 行為 |
| --- | --- |
| **桌面** ≥ 1280px | 1～3 欄並排 |
| **平板** 768–1279px | 最多 2 欄。開啟第三欄時，第一欄自動推出畫面，第二、三欄沿用三欄比例中兩者的相對寬度（25:50:25 → 67:33） |
| **行動** < 768px | 單欄；每一層以 slide-in 方式從右側滑入，標題列左側出現「‹」返回鍵，關閉鍵與比例控制隱藏 |

每一欄都設成 `container-type: inline-size`，內容依「欄寬」而不是視窗寬度調整：例如第一欄壓到 25% 時清單列改成上下堆疊；第二欄變窄時 KPI 改成兩欄、明細表收起 SKU 與單價欄。

## 其他

- 淺色／深色主題跟隨系統，也可用右上角 ◐ 手動切換。
- 支援 `prefers-reduced-motion`；隱藏的欄位設為 `inert`，鍵盤 Tab 不會跑進去。
- 比例、自訂寬度與主題存在 `localStorage`；無法存取時（如無痕模式）會退回預設值，不影響使用。
